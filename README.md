# 偶像大师闪耀色彩 · 剧情整合

THE iDOLM@STER SHINY COLORS STORY INTEGRATION

单文件静态页面：闪耀色彩 + 棱镜之歌（Song for Prism）双文档剧情导航。

## 功能

- ✦ **双文档**：主文档 2883 条 + 棱镜之歌 911 条剧情，点击卡片页内直接播放（B 站官方外链播放器）
- 🗓 **整体时序 / 整组时序**：按 2018–2026 年份分节的全剧情时间线
- 🃏 **原版卡面**：游戏官方卡面作为剧情卡片封面（来自 Shinycolors Wiki）
- ✓ **已读标记**：看过的剧情自动打标（存浏览器本地），可一键取消、只看未读、已读进度
- 🌙 **亮暗主题**：右上角切换，自动记忆
- 🔍 搜索偶像 / 组合 / 剧情名，组合筛选，继续观看

## 使用

直接打开 [index.html](https://qzymz.github.io/imas-story/) 即可，无需任何服务端。
